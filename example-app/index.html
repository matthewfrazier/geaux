Welcome to Geaux MCP Server

This is an example localhost application deployed using the Geaux MCP (Model Context Protocol) service.

Features:

  • Multi-environment deployment (dev, preprod, prod)
  • Secure credential management
  • API key configuration
  • Deployment history tracking
  • Version rollback support
  • GitHub integration
  • Play Store deployment
  • App Store deployment

Quick Start:

1. Install dependencies: npm install

2. Build the server: npm run build

3. Configure in your MCP client (Claude Desktop)

4. Start deploying with MCP tools!

Health Check:

Visit /health to see the service status
